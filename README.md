# Скролл текста по осям

Интерактивный текстовый стенд с двумя независимыми траекториями Безье: для основного текста и для заголовков с нумерацией.

Каждое предложение — отдельный фрагмент с абзацным отступом. Используется PT Mono. Панель позволяет менять кегль, цвета, градиент, виньетку и размытие фона. Настройки сохраняются в браузере. Пикселизация удалена.

## Локальный запуск

В каталоге проекта выполните:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000. Сборка и установка зависимостей не нужны.

## Структура

- `index.html` — текст и вёрстка.
- `axes.js` — фрагменты, траектории и настройки.
- `panel.js`, `panel.css`, `panel-lib/` — панель управления.
- `fonts.css`, `fonts/` — шрифты и лицензии.
